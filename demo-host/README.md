# نشر الموقع + الديمو الحقيقية على Hostinger (تطبيق Node.js)

ده تطبيق واحد بيشغّل: الموقع الشخصي على `/`، وديمو مسار HR على `/demo-hr`، وديمو الجوازات على `/demo-passports`.
البيانات كلها وهمية، وبترجع لأولها كل 60 دقيقة.

> ⚠️ **ارفعه كموقع لوحده** (دومين `ahmedalkholy.com` مثلاً). ماتحطوش على موقع `system.nisrelkhaleeg.com` ولا على أي نظام شغال فعلاً.
> الملف اللي بيتبني فيه نسخة من كود نظامي HR والجوازات، فماتحطوش على GitHub ولا ترفعه في أي مكان عام. هو بيترفع على Hostinger بس.

## أولاً: تجهيز ملف الرفع (على جهازك أو هنا)

محتاج ريبوهات `masar-hr-v3` و `nesr-passport-system` جنب الريبو ده في نفس الفولدر الأب.

```bash
cd nesr-passport-system/passport-app && npm ci
cd ../../almaher
node demo-host/build.js
```

الناتج: `ahmedalkholy-app.zip` في جذر الريبو. (الملفات جواه على طول، و `server.js` في أوله، ومن غير `node_modules`.)

## ثانياً: قاعدة بيانات الجوازات

1. في hPanel ← **Databases ← MySQL Databases**، اعمل قاعدة جديدة **فاضية** ويكون اسمها فيه كلمة `demo` (مثلاً `u123_demo_pp`).
2. اعمل لها مستخدم وباسورد، واديله كل الصلاحيات على القاعدة دي بس.

> ⚠️ التطبيق **بيمسح كل جداول** القاعدة دي كل ساعة ويحط بدالها بيانات وهمية. ولذلك بيرفض يشتغل لو الاسم مفيهوش `demo`. **ماتستخدمش أبداً قاعدة نظام شغال.**

## ثالثاً: الرفع

1. hPanel ← **Websites ← Add website** ← **Node.js Apps** (أو "انشر تطبيق ويب") ← **Upload your website files**، وارفع `ahmedalkholy-app.zip`.
2. الإعدادات: Framework = **Express.js**، Node = **22.x**، Entry file = **`server.js`**.
3. **Environment variables** (متغيرات البيئة):

| الاسم | القيمة |
|---|---|
| `DEMO_PASSPORTS_DB_NAME` | اسم القاعدة (فيه `demo`) |
| `DEMO_PASSPORTS_DB_USER` | مستخدم القاعدة |
| `DEMO_PASSPORTS_DB_PASSWORD` | باسورد المستخدم |
| `DEMO_PASSPORTS_DB_HOST` | اختياري، الافتراضي `127.0.0.1` (جرّب `localhost` لو ماشتغلش) |
| `DEMO_RESET_MINUTES` | اختياري، الافتراضي `60` (أقل حاجة 10) |

   ماتحطش `PORT`، Hostinger بيحدده لوحده.
4. اربط الدومين وفعّل SSL، وبعدين دوس **Deploy**.
5. استنى دقيقة أو اتنين لحد ما يشتغل، وبعدين افتح:
   - `https://دومينك/` ← الموقع
   - `https://دومينك/demo-hr/` ← مسار HR
   - `https://دومينك/demo-passports/` ← الجوازات

لو الجوازات كتب «لسه بيتجهّز» → راجع المتغيرات الـ3 واسم القاعدة، وشوف **Runtime logs** في لوحة التطبيق.

## بعد كده

- تعدّل في الموقع أو الديمو: اعمل `node demo-host/build.js` تاني وارفع الـ zip الجديد (Redeploy). مفيش حاجة مهمة بتتمسح لأن كل البيانات وهمية.
- الديمو بيقفل العمليات الحساسة (المستخدمين، الأمان، الاستعادة، الإعدادات) علشان الزوار مايبوّظوش حاجة. القايمة في `apps.config.js`.
- كل نظام بيشتغل كعملية لوحده، لو وقع بيتعاد تشغيله لوحده.
