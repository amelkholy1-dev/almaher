# موقع أحمد ماهر الخولي — بلوحة تحكم كاملة

موقع شخصي بالعربي والإنجليزي، مبني كتطبيق Node.js واحد بلوحة تحكم تعدّل منها **كل حاجة**: النصوص، الخدمات، المشاريع بصورها وديموهاتها، المهارات، الخبرات، أقسام جديدة بالكامل، الصور والملفات، ورسائل الزوار.
مفيش قاعدة بيانات. المحتوى في ملف JSON، والصور المرفوعة في فولدر برّه التطبيق، فإعادة النشر ماتمسحش حاجة.

الكود كله في فولدر `app/`.

## النشر على Hostinger (تطبيق Node.js)

زي موقع روك لاين بالظبط.

1. اعمل الملف: `cd app && zip -r ../ahmedalkholy-site.zip . -x "node_modules/*"` (أو استخدم الملف الجاهز اللي اتبعتلك). **`server.js` لازم يكون في أول الـ zip.**
2. hPanel ← **Websites** ← **Add website** ← **Node.js Apps** ← ارفع الـ zip.
3. الإعدادات: Framework = **Express.js**، Node = **22.x**، Entry file = **`server.js`**.
4. **Environment variables:**

| الاسم | القيمة |
|---|---|
| `ADMIN_USER` | اسم دخول اللوحة (مثلاً `ahmed`) |
| `ADMIN_PASS` | كلمة مرور قوية (10 حروف على الأقل) |
| `SESSION_SECRET` | أي حروف عشوائية طويلة (16 على الأقل) |
| `SITE_URL` | `https://ahmedalkholy.com` (عشان صورة مشاركة الرابط) |

   ماتحطش `PORT`. Hostinger بيحدده.
5. اربط الدومين وفعّل SSL، وبعدين **Deploy**.
6. افتح `https://دومينك/` للموقع، و`https://دومينك/admin` للوحة التحكم.

> لو ماحطيتش `ADMIN_PASS`، التطبيق بيولّد كلمة مرور مؤقتة ويكتبها **مرة واحدة** في Runtime logs. ادخل بيها وغيّرها من «الحساب».

## لوحة التحكم (`/admin`)

| التبويب | بتعمل فيه إيه |
|---|---|
| الإعدادات العامة | الاسم والمسمى والجملة التعريفية، الصورة، السيرة الذاتية، الإيميل وواتساب وLinkedIn، عنوان ووصف جوجل ومعاينة الرابط |
| الأرقام السريعة | الأرقام اللي تحت الصفحة الرئيسية |
| نبذة / طريقة العمل / الخدمات | كل النصوص بالعربي والإنجليزي، وإضافة وحذف وترتيب العناصر |
| **المشاريع** | إضافة أي مشروع (نظام، موقع، تطبيق، نموذج)، صوره، ديمو تفاعلي، رابط، حالة، إخفاء وإظهار، ترتيب |
| الخبرات / المهارات | وظائف ومجموعات مهارات، وكل مهارة سطر |
| **أقسام إضافية** | أنشئ أي قسم جديد (شهادات، عملاء، أخبار…) بشكل نص أو بطاقات أو معرض صور |
| ترتيب الأقسام | رتّب أقسام الصفحة، واخفِ أي قسم، وتحكّم في القائمة العلوية |
| الصور والملفات | رفع صور وPDF وفيديو وExcel، وحذفها |
| الرسائل | رسائل الزوار من نموذج «إرسال مباشر»، وزرار رد بواتساب أو إيميل |
| الحساب والنسخ الاحتياطي | تغيير كلمة المرور، استرجاع نسخة قديمة (بتتعمل تلقائياً قبل كل حفظ)، تنزيل واستيراد المحتوى |

بعد أي تعديل اضغط **حفظ التعديلات**، والتغيير بيظهر في الموقع فوراً.

### الصياغة والنصوص
كل النصوص اتكتبت بصياغة احترافية، وتقدر تغيّر أي جملة. راجع قسم **المهارات** على وجه الخصوص، وامسح أي مهارة مش بتعملها فعلاً قبل ما تعتمد الموقع.

### النماذج التوضيحية
المشاريع الـ 8 المعلّمة «نموذج توضيحي» (المخازن، الفواتير، النقل، العقارات، العيادات، المدارس، تطبيق المطاعم، المتجر) ديموهات تفاعلية ببيانات وهمية بالكامل، ومكتوب عليها إنها نماذج. لو عايز تضيف أو تغيّر أو تخفي أي واحد، من تبويب **المشاريع**.

## التحديث لاحقاً
لو غيّرت الكود: اعمل zip جديد وارفعه من «عمليات النشر». المحتوى والصور والرسائل وكلمة المرور محفوظين في `~/ahmedalkholy-data` (برّه التطبيق) فمش بيتأثروا.

## الأمان
- كلمة المرور مشفّرة (scrypt)، والجلسة موقّعة وفي كوكي `HttpOnly` و`SameSite=Strict`، وحد لمحاولات الدخول (8 كل 15 دقيقة).
- أي تعديل لازم يكون من مدير مسجّل مع هيدر حماية (CSRF).
- رفع الملفات بيتحقق من النوع ومن محتوى الملف الحقيقي، ومفيش رفع HTML أو سكربتات.
- كل نصوص المحتوى بيتعملها escape قبل العرض.
- نموذج التواصل فيه حد (5 رسائل في الساعة) وفخ للروبوتات.

## هيكل الملفات
```
app/
  server.js            السيرفر وكل المسارات
  lib/                 التخزين، الدخول، رسم الصفحة
  seed/content.json    المحتوى الافتراضي (بيتبني من tools/build-seed.js)
  public/index.template.html   قالب الصفحة
  public/assets/       الستايل والصور وملفات الديمو
  public/admin/        لوحة التحكم
```
