# موقع أحمد ماهر الخولي — Ahmed Maher Alkholy

موقع شخصي ثابت (HTML / CSS / JS) جاهز للرفع على **Hostinger** (استضافة مشتركة)، من غير سيرفر ولا قاعدة بيانات.

- `site/` ← ملفات الموقع نفسها.
- 4 عروض تفاعلية جوه الموقع: نظام العمليات والحسابات، ونظام مسار HR، ولوحة تحكم المواقع، وتطبيق وصال.
- `ahmed-alkholy-website.zip` ← نفس الملفات مضغوطة، وهي **على طول جوه الـ zip** (من غير فولدر جواه)، جاهزة تتفك في `public_html`.

---

## 1) محتوى الموقع

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة كلها (بالعربي) + بيانات SEO و Open Graph |
| `assets/css/style.css` | تصميم الموقع (الألوان في أول الملف تحت `:root`) |
| `assets/js/main.js` | تبديل اللغة، والوضع الليلي، والمعارض، وعارض الصور، والفيديو، ونموذج التواصل. **الترجمة الإنجليزية موجودة هنا** |
| `assets/css/demo.css` + `assets/js/demo.js` | الديمو التفاعلي للنظامين (بيتحمّل بس لما الزائر يفتحه، عشان الموقع يفضل سريع) |
| `.htaccess` | ضغط الملفات وتخزينها في المتصفح (Cache)، ومنع عرض محتويات الفولدرات |

**مميزات:**

- عربي وإنجليزي. الموقع بيفتح بلغة جهاز الزائر، وبيفتكر اختياره.
- وضع ليلي تلقائي حسب جهاز الزائر، وفيه زرار تبديل.
- متجاوب مع الموبايل.
- ديمو تفاعلي لكل نظام ببيانات وهمية بالكامل، وفوقه عبارة: «عرض توضيحي تفاعلي ببيانات تجريبية – النظام الكامل متاح عند الطلب».
- كل زرار «اطلب ديمو مباشر» بيفتح واتساب برسالة جاهزة باسم النظام.

## 3) خطوات الرفع على Hostinger (خطوة بخطوة)

### أ) قبل الرفع: حط الدومين بتاعك (مهم عشان صورتك تظهر لما اللينك يتبعت)
1. افتح `index.html` بأي محرر نصوص (Notepad أو VS Code).
2. اعمل **بحث واستبدال** (Ctrl + H): غيّر كل `YOUR-DOMAIN.com` للدومين بتاعك، مثلاً `ahmedalkholy.com`. هتلاقيها في أول الملف جوه الـ `<head>`.
3. احفظ الملف.

> لو هتعمل الخطوة دي بعد الرفع، تقدر تعدّل الملف من File Manager مباشرة (كليك يمين على `index.html` ثم **Edit**).

### ب) الرفع
1. ادخل على **hpanel.hostinger.com** وسجّل دخول.
2. من **Websites** اختار موقعك، ودوس **Dashboard** (أو **Manage**).
3. من القايمة اختار **Files ← File Manager**.
4. افتح فولدر **`public_html`**.
5. لو فيه ملفات قديمة زي `default.php` أو `index.php`، **امسحها**، لأنها ممكن تظهر بدل موقعك.
6. دوس زرار **Upload** (السهم لفوق) ← **File**، واختار `ahmed-alkholy-website.zip`.
7. بعد ما يخلص الرفع: كليك يمين على ملف الـ zip ← **Extract**، وسيب مكان الفك فاضي أو `.` عشان يتفك **جوه `public_html` نفسه**.
8. اتأكد إن `index.html` بقى موجود **مباشرة جوه `public_html`**، مش جوه فولدر تاني.
9. امسح ملف الـ zip من `public_html` بعد الفك.
10. افتح الدومين في المتصفح، والموقع هيشتغل. 🎉

### ج) تفعيل HTTPS (القفل الأخضر)
1. من hPanel: **Security ← SSL**، واتأكد إن الشهادة **Active**. Hostinger بيديها مجاناً، وممكن تاخد شوية وقت لحد ما تتفعل.
2. بعد ما تتفعل: افتح `.htaccess` من File Manager، وشيل علامة `#` من أول **3 سطور** تحت عبارة «تحويل كل الزيارات إلى https».
   > لو مش شايف `.htaccess`: من File Manager فعّل **Show hidden files** من الإعدادات.

### د) إضافة صورك وملفاتك بعدين
1. من File Manager ادخل على الفولدر المناسب، مثلاً `public_html/assets/img/projects/`.
2. دوس **Upload** وارفع الصور بنفس الأسماء اللي في الجدول.
3. اعمل تحديث للموقع (Ctrl + F5)، والصور هتظهر لوحدها.

### هـ) اختبار شكل اللينك على واتساب و LinkedIn
- LinkedIn: افتح **linkedin.com/post-inspector**، وحط لينك موقعك، عشان يحدّث الصورة.
- Facebook / واتساب: افتح **developers.facebook.com/tools/debug**، وحط اللينك، ودوس **Scrape Again**.
- واتساب ساعات بيحتفظ بالصورة القديمة لفترة. ولو عايز تجرّب بسرعة، ابعت اللينك ومعاه `?v=2` في الآخر.

## 4) تعديلات سريعة

- **رقم الواتساب أو الإيميل أو أسماء ملفات السيرة الذاتية:** فوق في `assets/js/main.js` (`CONFIG`)، وكمان في `index.html`. ابحث عن `201552084471` وعن `am.elkholy1@gmail.com`.
- **نص رسائل واتساب الجاهزة:** `WA_MSG` في `assets/js/main.js`.
- **أي نص عربي:** عدّله في `index.html`. **ومقابله الإنجليزي:** في `EN` جوه `assets/js/main.js`، بنفس المفتاح (`data-i18n`).
- **الألوان:** أول ملف `assets/css/style.css` (`--navy`، `--blue`، `--gold`).
